# Security

A homeserver holds people's conversations. If you find a way to read, forge or destroy what
it holds, or to take over an account or the server, please report it privately so that it can
be fixed before it is known.

**How:** use "Report a vulnerability" under the Security tab of this repository on GitHub
(private vulnerability reporting). Say what you did, what happened and which commit or
version you tried it on; a request that shows it is the best report.

**What to expect:** an answer within a week. This is a small project without a security
team, so a fix may take longer than that, and you will be told what is being done. Reports
are credited in the fix unless you would rather not be named.

Only the latest commit on `main` is maintained; there are no supported older versions yet.
